# Large routing scene dataset

This directory is generated by:

```bash
python scripts/prepare_large_geojson_dataset.py
```

It contains 353 routing scenes selected from 400 real OpenStreetMap windows in
`data/real_geojson_places`. Every connection point is anchored inside a real
OSM building footprint and carries that building's OSM identifier. Consumer
selection, heat demand, source, existing heat network and chamber remain
explicit synthetic proxies. The four research buckets are scenario families,
not ground-truth optimal routing labels.

Geographic seeds are kept entirely in one of `train`, `validation` or `test`.
`scene_manifest.json` records source and generated hashes, counts and split
membership. Validate all scenes through the actual Java parser and solver with:

```bash
python scripts/validate_large_geojson_dataset.py --workers 6
```

After validation, build the checked 112-scene proposal dataset used by R1/R2:

```bash
python scripts/r1/build_large_dataset.py --workers 4
```
