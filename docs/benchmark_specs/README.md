# Как читать и использовать пакет

**Сначала откройте `NETWORK_OPTIMIZATION_IMPLEMENTATION.md`.** В нём описаны общая среда, полный расчёт, контрольные алгоритмы B0/B1, взвешенная магистраль B2, ALNS B3, основной обучаемый агент R1/PPO, дополнительный R2 и точный малый эталон X0.

## Файлы

| Файл | Назначение |

| `NETWORK_OPTIMIZATION_IMPLEMENTATION.md` | Основная спецификация всех алгоритмов, обучения и порядка реализации |

## Проверить контрольную арифметику

```bash
python reference_checks.py --output numeric_reference_results.json
```

Запуск проверяет: тарифные границы; выгоду/невыгоду двух предписанных шаблонов общей ветви; выбор дальней врезки вместо ближней с реконструкцией; интервалы реконструкции; различие среднего и взвешенного центра; награду RL; эквивалентность двух записей оценки. Результаты хранятся точными десятичными строками.

Ни один из этих примеров не доказывает геометрическую допустимость сети на реальной карте. В отчёте это явно отражено: `geometry_checked=false`, `java_solver_executed=false`, `rl_trained=false`.

## Что нужно реализовать

Java-среду и независимый checker, входные/выходные GeoJSON-фикстуры, B0/B1/B2/B3, обучение и inference R1, затем воспроизводимые сравнительные прогоны. R2 — дополнительный эксперимент. Источники кода в `RESEARCH_MAP.md` — референсы; сторонний код в пакет не скопирован.

Предыдущие документы пользователя не перезаписаны. Новый пакет явно меняет исследовательский приоритет: RL — основной обучаемый кандидат, общая магистраль — отдельная проверяемая гипотеза, A* — возможный внутренний построитель пути.

## До обучения необходимо решить

Разрешено ли отдельное обучение вне Java при полностью Java/offline поставке. В документах указан предлагаемый путь с внешним trainer, но разрешение не предполагается автоматически. Расходы и `oks_id` реального набора также должны быть получены из его действительных полей, не из скриншота.

Статус реального датасета: сохранена переданная командой сводка 144 объектов/17 точек; фактический input/output GeoJSON в этом пакете отсутствует. Текущий набор не использован для обучения и измерения качества в этой работе.
