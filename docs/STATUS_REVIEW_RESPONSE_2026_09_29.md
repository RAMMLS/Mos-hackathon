## Исправление CH 01

До исправления checker выбирал ближайшую камеру и применял к ней проверку:

`diameter камеры >= max diameter примыкающих новых труб`.

Это правило ошибочно применялось и к существующим входным камерам без объявленного диаметра.

После исправления:

- объявленный `start_node_id` или `end_node_id` разрешается по ID раньше географического поиска;
- геометрия конца трубы отдельно проверяется относительно объявленного узла;
- близкая существующая камера не подменяет явную ссылку;
- для технической развилки географически ищется только новая выходная камера;
- диаметр и стоимость проверяются только у новой выходной камеры;
- для существующей камеры сохраняются проверки числа примыканий и стоимости врезки.

Добавлены smoke-тесты:

- существующая камера без `diameter` не получает выдуманный предел;
- при двух соседних камерах выбирается точная камера, а не первая feature;
- перестановка соседних features не создаёт ложное нарушение диаметра.
