## Динамическая проверка B1

Через актуальный Java API проверены все 1644 сцены:

- VALID: 1580.
- INVALID: 26.
- ERROR по вычислительному лимиту: 38.
- Контрактно валидные и полностью подключённые: 1379.
- Контрактно валидные с частичным или нулевым подключением: 201.

`INVALID` не означает повреждённый GeoJSON. Это результат, нарушающий строгий
контракт маршрута, например запрет прохождения через ограничивающую геометрию.
`ERROR` также не означает повреждённый файл: эти сцены корректно читаются, но
B1 не завершает тяжёлый поиск за 600 секунд при параллельном прогоне.
