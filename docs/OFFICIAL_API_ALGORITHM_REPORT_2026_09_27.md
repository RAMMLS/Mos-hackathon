# Официальный контур алгоритма и API

Дата: 2026-09-27  
Статус: актуальный production-профиль

## Правило ТЗ

Официальный профиль `DOCUMENT_NEAREST_V1` реализует п. 2.2 технического приложения:
конечный участок от ближайшей границы ОКС проводится до точки подключения. Solver и
независимый checker применяют одно имя профиля, но проверяют результат разным кодом.

`EXPERIMENTAL_ANY_BOUNDARY_V1` оставлен для исследований. Его результаты нельзя
сравнивать с официальными как конкурсное улучшение.

## API

`POST /api/trace` принимает multipart-поле `file` и параметры:

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `algorithm` | `PORTFOLIO` | Один из алгоритмов `GET /api/trace/algorithms` |
| `budgetMs` | `0` | Общий бюджет, 0 означает внутренний default |
| `entryStrategy` | `AUTO` | `AUTO`, `DIRECT_ALLOWED`, `PORTAL_ONLY` |
| `ruleset` | `DOCUMENT_NEAREST_V1` | Официальный или явно экспериментальный профиль |

Пример официального запуска:

```bash
curl -F "file=@scene.geojson" \
  "http://localhost:8080/api/trace?algorithm=PORTFOLIO&budgetMs=120000&entryStrategy=AUTO&ruleset=DOCUMENT_NEAREST_V1" \
  -o result.geojson
```

Checker должен запускаться с тем же `--ruleset DOCUMENT_NEAREST_V1`.

## Контрольный результат

На сцене `076_innopolis_-1_-3_f0abd3bb.geojson` официальный `PORTFOLIO` получил:

| Валидность | Подключение | Длина | Стоимость | Score | Время | Нарушения |
|---|---:|---:|---:|---:|---:|---:|
| VALID | 6/6 | 527.86 м | 74 473 341.01 руб. | 3.67 | 5.721 с | 0 |

Машинные артефакты: `results/official-nearest-innopolis-2026-09-27/`.

Полный API-прогон 15 реализаций на той же сцене: все ответы прошли checker без
нарушений; 12 алгоритмов подключили 6/6 ОКС. Все полные решения совпали по качеству
(`527.86 м`, `74 473 341.01 руб.`, `score=3.67`). Самым быстрым в этом запуске был
один из B2-вариантов; конкретный порядок меняется на десятые доли секунды между
повторами. Это ничья по качеству, а не доказательство общего превосходства B2:
production default остаётся `PORTFOLIO`,
поскольку на иных сценах он выбирает лучший проверенный incumbent из нескольких
семейств. Полный отчёт и manifest:
`results/official-all-algorithms-innopolis-2026-09-27/`.

Это актуальная официальная контрольная точка. Прежний результат `score=2.96` получен
по экспериментальному правилу входа с любой стороны и не считается улучшением по ТЗ.

## Надёжность

- API по умолчанию не может случайно включить экспериментальный профиль.
- Неверные `ruleset` и `entryStrategy` возвращают HTTP 400.
- Route cache разделён по профилю и роли маршрута.
- Пустой маршрут, полученный из-за таймаута, не кэшируется как геометрически невозможный.
- Дочерние стратегии ограничены общим дедлайном `budgetMs`, включая малые бюджеты.
- Checker фиксирует `checker_version` и `ruleset_version` в JSON-отчёте.
