## Что реализовано

| Код | Реализация | Граница полноты |
|---|---|---|
| B0-GRID | Независимые подключения, прямой путь и 8-связный A* | Полный исполняемый baseline текущего ядра |
| B0-CORRIDOR | Независимые подключения, прямой путь, обходы по углам препятствий и A* | `lite`: еще не общий предрасчитанный corridor graph |
| B1 | Regret-2, подключение к построенным узлам, полный пересчет расходов и камер | `lite`: нет вставки в произвольную внутреннюю точку трубы и группового merge |
| B2-U/Q/C | Взвешенный медоид, три порядка формирования магистрали, выбор лучшего | `lite`: нет виртуальных узлов магистрали внутри ребер |
| B2-C-J | B2-C плюс транзакционные развилки внутри новых труб | v1: ортогональная проекция, до пяти ближайших базовых участков |
| B3 | Общий архив B0/B1/B2, фиксированные destroy/repair-перестановки, выбор лучшего | `lite`: нет адаптивных весов операторов и удаления поддеревьев на уровне ребер |
| R1 | API-контракт и явный статус отсутствующей модели | PPO-модель и training pipeline отсутствуют; запуск честно возвращает `NOT_TRAINED` |
| R2 | API-контракт и явный статус отсутствующей модели | Обученный контроллер ALNS отсутствует; запуск честно возвращает `NOT_TRAINED` |
| X0 | Полный перебор порядков вставки при количестве ОКС не более 6 | Точность ограничена текущим конечным shortlist маршрутов, это еще не полный перебор общего candidate graph |

## Как воспроизвести

```bash
docker compose up -d --build
python scripts/run_algorithm_benchmark.py
python scripts/run_algorithm_benchmark.py \
  --input data/benchmark_fixtures/new_tz_smoke/input.geojson \
  --out-dir results/algorithm-benchmark-x0-smoke \
  --algorithm X0
python scripts/benchmark_smoke_tests.py
python scripts/run_numeric_benchmarks.py
python scripts/run_benchmark_suite.py
```

Полный машинный отчет создается в `results/algorithm-benchmark/summary.json`, читаемая таблица — в
`results/algorithm-benchmark/summary.md`. Рейтинг включает только решения, которые прошли независимый checker
и подключили все входные ОКС.

## Следующий этап

До заявления «все алгоритмы реализованы полностью» остаются четыре самостоятельные работы:

1. настоящий общий corridor graph;
2. подключение junction-позиций к B1 и групповые объединения;
3. полный edge-level ALNS для B3;
4. генератор training-сцен, PPO-обучение, versioned model artifacts и inference для R1/R2.

Текущий лучший проверенный кандидат — `B2-C-J` с обязательной проверкой результата. `R1/R2`
нельзя включать в рейтинг качества до появления обученной модели и зафиксированного train/validation/test split.
