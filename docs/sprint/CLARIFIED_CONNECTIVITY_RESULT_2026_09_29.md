## Источник правила

`docs/spec/clarifications_2026_09_29/additional_clarifications_2026-09-29.docx`,
вопросы 15-17. Пункт 15 разрешает другую подходящую точку **внешней** границы,
если через ближайшую допустимую точку нельзя построить допустимый и рациональный
маршрут. Пункты 16-17 подтверждают прямой финальный участок и отсутствие
обязательного перпендикулярного входа. Внутреннее кольцо (двор) не считается
внешней границей. Горизонтальные отступы и остальные запреты не ослаблялись.

## Изменение

- Официальный профиль `CLARIFIED_EXTERIOR_BOUNDARY_V1` стал умолчанием API,
  solver-а и независимого checker-а. Старый `DOCUMENT_NEAREST_V1` сохранён
  для сравнения; `EXPERIMENTAL_ANY_BOUNDARY_V1` не является доказательством.
- Кандидаты входа сортируются по расстоянию до точки подключения, допускаются
  только точки внешней границы. Прямой конечный участок и единственный выход
  из собственного полигона проверяются в Java и Python независимо.
- Для нового профиля одновременно рассматривается не более шести входов,
  чтобы не размножать пары поисков маршрутов. Кэш маршрутов отделён по профилю.
- Правило прежнего локального блокера не применяется к новому профилю.
