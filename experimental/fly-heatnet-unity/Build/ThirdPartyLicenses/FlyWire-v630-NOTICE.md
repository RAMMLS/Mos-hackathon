# FlyWire v630 connectome runtime data

The runtime asset `FlyWireV630.bytes` was generated from the v630 neuron and
connectivity tables distributed with `philshiu/Drosophila_brain_model`, commit
`91bdd1e7dcf193f3e7ca5a8933497fcef63b7960`.

The simulation follows the leaky integrate-and-fire constants published in
that reference implementation. Heat-network features, input-neuron mapping,
the fixed readout head, and Unity visualization are project-specific additions.
